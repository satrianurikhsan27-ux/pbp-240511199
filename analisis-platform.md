# Analisis Komparatif Platform: Web, Desktop, dan Mobile

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Bahasa Utama** | HTML, CSS, JavaScript, TypeScript | C#, C++, Java, Python, Swift | Kotlin, Swift, Java, Dart, JavaScript (React Native) |
| **Arsitektur** | Klien-Server (Client-Server), Single Page Application (SPA), Model-View-Controller (MVC) | Model-View-ViewModel (MVVM), Model-View-Controller (MVC), Standalone Client | Model-View-ViewModel (MVVM), Model-View-Presenter (MVP), BLoC |
| **Cara Distribusi** | Melalui web server (diakses via browser menggunakan URL/domain) | Installer mandiri (.exe, .msi, .dmg, .pkg, AppImage/Flatpak) | Official App Store (Google Play Store, Apple App Store, pihak ketiga) |
| **Keunggulan** | - Tidak perlu instalasi khusus oleh pengguna <br>- Mudah diakses dari berbagai perangkat lintas platform <br>- Pembaruan aplikasi dapat dilakukan terpusat di server | - Performa tinggi dan akses penuh ke hardware lokal <br>- Dapat berjalan secara offline dengan stabil <br>- Keamanan data lokal yang lebih terkontrol | - Integrasi mendalam dengan fitur perangkat (GPS, kamera, sensor) <br>- Mobilitas tinggi dan selalu diandalkan pengguna <br>- Notifikasi push yang efektif untuk keterlibatan pengguna |
| **Keterbatasan** | - Bergantung penuh pada koneksi internet dan performa browser <br>- Akses terbatas terhadap hardware perangkat keras <br>- Fragmentasi ukuran layar dan perilaku browser yang beragam | - Distribusi dan pembaruan aplikasi membutuhkan tindakan manual pengguna <br>- Ukuran file instalasi cenderung besar <br>- Harus dibangun secara spesifik per sistem operasi (kecuali menggunakan framework lintas platform) | - Kapasitas memori (RAM) dan baterai perangkat yang terbatas <br>- Proses peninjauan (review) di app store yang ketat sebelum rilis <br>- Fragmentasi ukuran layar, resolusi, dan versi OS yang tinggi |
| **Contoh Aplikasi** | - Google Workspace / Google Docs <br>- Netflix <br>- Trello | - Microsoft Office (Word, Excel) <br>- Visual Studio Code <br>- Adobe Photoshop | - WhatsApp <br>- Instagram <br>- Google Maps |
